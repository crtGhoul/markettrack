🔑 1 · Google AI Studio (Gemini) API key

What it powers: AI fill-in + nutrition-label photo scan in Foods. Where it goes: paste it in the box below — this is the Gemini key, not the USDA key. Everything else works without it.

  1. Open aistudio.google.com/apikey and sign in with Google.
  2. Tap Create API key — it's free.
  3. Copy the key, paste it below, and tap Save.

Your key is saved only in this browser, on this device, and is sent only to Google when you use an AI feature.

Backup Gemini key — optional, fallback only

Add a second Gemini key here if you have one — for example from a free project. It is used automatically only if your main key above fails (out of credit, daily limit, or a model issue). If the main key works, the backup is never used. Leave it blank to keep using just your main key, exactly as today. The app also falls back to the lighter Flash-Lite model automatically if the main model fails.

Backup key is saved only in this browser, on this device, and is sent only to Google when a Gemini call needs the fallback.

🌾 2 · USDA FoodData Central API key

What it powers: USDA search in Foods — a second search that catches US branded products Open Food Facts misses. Where it goes: paste it in the box below — this is the USDA key, not the Gemini key above. Free, 1,000 searches an hour.

  1. Open api.data.gov/signup and sign up — the key arrives by email.
  2. Copy the key from that email, paste it below, and tap Save.

Your key is private to this browser — it's saved only on this device, sent only to api.nal.usda.gov when you search, and should not be shared.
