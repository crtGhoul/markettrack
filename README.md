# MarketTrack

Free calorie counter that runs entirely in your browser. Log food, water, weight, and activity, with a grocery food index (H-E-B, Walmart, Sam's Club, Joe V's), a daily target calculator, and a Google AI Studio key for AI nutrition fill-in and label scans.

- No account, no server. Your logs, targets, profile, and API key are saved in your browser on the device you use it on. They don't sync between devices.
- Open `index.html` in any browser, or add it to your phone's home screen to use it like an app.
- Type the grams you ate and nutrition scales automatically from the serving size.

Built with Muse. Testing now — it joins Velazquez Lab later.
